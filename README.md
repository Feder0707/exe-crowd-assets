# EXE CROWD · assets

Hosted assets for the **EXE CROWD** StreamElements widget by form&soul.exe (Etsy: FormAndSoul).
Buyers do not need to touch this repository: the widget loads everything from here automatically.

- `engine/crowd.js` · widget engine (version in the first line)
- `assets/` · artwork (WebP) + `scene.json`
- `fonts/` · Fredoka (SIL Open Font License, see `OFL-Fredoka.txt`)
- `sounds/` · sound effects
- `index.html` · live preview

Please do not rename or move files: purchased widgets load from these exact paths.
